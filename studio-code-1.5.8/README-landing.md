# Studio Code 1.5.8

Studio Code 1.5.8 est une version personnalisée du projet ZeroScript, adaptée pour fonctionner comme outil d’extension Robox Studio + MCP + IA navigateur.

## Contenu

- Extension Chrome / Edge
- Bridge local Python
- Serveur MCP Roblox Studio
- Plugin de personnalisation et de providers IA
- Page de téléchargement / landing page

## Installation

1. Télécharge le dossier ZIP du projet.
2. Décompresse-le sur ton ordinateur.
3. Ouvre Chrome ou Edge avec le mode développeur activé.
4. Charge le dossier `zeroscript-extension` en tant qu’extension non empaquetée.
5. Ouvre Roblox Studio et active le serveur MCP.
6. Lance `start.bat` sur Windows.
7. Utilise un site IA supporté et commence la session.

## Personnalisation

Tu peux modifier :
- le nom de l’extension
- la version
- le branding
- les sites IA supportés
- le provider custom
- la landing page de téléchargement
