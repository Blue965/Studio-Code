Installation

3 étapes simples pour démarrer.

1

Télécharger

Récupère le package Studio Code et décompresse le dossier sur ton ordinateur.

2

Activer l’extension

Dans Chrome/Edge, active le mode développeur puis charge le dossier de l’extension.

3

Lancer le bridge

Ouvre Roblox Studio, active le MCP puis lance start.bat ou le script macOS.

4

Commencer la session

Choisis un site IA compatible, ouvre un chat, et démarre la session Roblox.
